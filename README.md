# homebrew-tap

Homebrew tap for [WuZuo](https://github.com/yinx0004/wuzuo), an AI forensic
examiner for production database incidents.

```bash
brew install yinx0004/tap/wuzuo
```

Works on macOS and Linux. Only stable releases are published here, not
pre-releases.

`Casks/wuzuo.rb` is generated and committed by WuZuo's release workflow on
each stable release. Do not edit it by hand: changes are overwritten by the
next release. Report problems at https://github.com/yinx0004/wuzuo/issues.
